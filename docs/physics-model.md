# h3d v0.0.1 物理模型说明

模型文件：`models/upper_body.xml`（MJCF，MuJoCo 3.17.0）。`node src/cli.ts info` 打印的是 MuJoCo 实际编译出来的质量、关节和执行器参数。

当前研究主线是第 8、9 节的肌肉骨骼动力学与控制。第 1 至 7 节描述保留的 A/B/C 球拍动力链外围实验；它不被核心肌肉仿真模块依赖。

## 1. 坐标系与自由度

- 世界坐标：x = 击球方向（前），y = 球员左侧，z = 竖直向上。单位制 SI，角度在配置文件里用度，内部用弧度。
- 双腿固定在地面上（只是可视几何，没有质量），骨盆在髋关节中心高度（0.92 m）绕竖直轴转动。
- 5 个铰链自由度，都由力矩电机驱动：

| 关节 | 父 → 子 | 轴（qpos = 0 时） | 范围 (deg) | 阻尼 (N·m·s/rad) | 刚度 (N·m/rad) | gear = 力矩上限 (N·m) |
| --- | --- | --- | --- | --- | --- | --- |
| `pelvis_rot` | 地面 → 骨盆 | z | -70 … 70 | 0.5 | 0 | 200 |
| `trunk_rot` | 骨盆 → 躯干（腰椎轴向扭转） | z | -50 … 50 | 0.5 | 150（中性位 0） | 150 |
| `shoulder_hadd` | 躯干 → 右上臂（肩水平内收） | z | -60 … 135 | 0.2 | 0 | 100 |
| `elbow_flex` | 上臂 → 前臂（肘屈） | z | 0 … 145 | 0.1 | 0 | 70 |
| `wrist_flex` | 前臂 → 手（腕屈） | z | -70 … 80 | 0.05 | 0 | 15 |

参考姿态（qpos = 0）下右臂在冠状面外展 90°，掌心朝 +x。所以肩水平内收、肘屈、腕屈的轴都是竖直的，整条链在水平面（横断面）内运动。正角度表示向前挥拍（俯视逆时针）。重力由铰链约束承担，不做功。脊柱扭转弹簧是唯一的被动弹簧，因此任何 `trunk_rot = 0` 的姿态在零力矩下都是精确的静平衡（`test/model.test.ts` 有验证）。

## 2. 体段参数

体段参数按 de Leva (1996) 男性表缩放到 75 kg。惯量是相对体段质心、在体坐标系下的主惯量 (kg·m²)。体坐标系的约定：x 是矢状（前后）方向，z 是竖直方向；躯干类体段 y 为横向、z 为纵轴；手臂体段沿 -y 方向，所以 y 是纵轴、z 是横向。因为所有铰链轴都是竖直的，真正影响运动的只有 I_zz 和质心位置。

| --- | --- | --- | --- | --- | --- |
| 骨盆（de Leva lower trunk） | 8.378 | 髋中心上方 0.057 m | 0.0673 | 0.0540 | 0.0613 |
| 躯干（upper + middle trunk 合并） | 24.218 | 腰椎关节上方 0.250 m | 0.922 | 0.658 | 0.429 |

| 右上臂 | 2.033 | 肩关节外侧 0.163 m | 0.0131 | 0.0040 | 0.0117 |
| 右前臂 | 1.215 | 肘关节外侧 0.123 m | 0.0067 | 0.0013 | 0.0062 |

- 节段长度：上臂 0.282 m，前臂 0.269 m，腕到拍柄端 0.04 m，肩关节中心距躯干中线 0.19 m、高于腰椎关节 0.37 m（离地 1.436 m）。
- 合并躯干：上躯干和中躯干两段按平行轴定理合并（质心以颈椎点 CERV 为基准，腰椎点 OMPH 在其下方 0.458 m）。
- 球拍：质量 300 g，平衡点距拍柄端 0.33 m，挥重 320 kg·cm²（转轴距拍柄端 0.10 m），扭重 14 kg·cm²。I_zz（挥拍轴）= 挥重 − m·(0.33 − 0.10)² = 0.01613 kg·m²。
- 测点：`racket_head` 位于拍面（弦床）中心，距拍柄端 0.52 m；`racket_butt` 在拍柄端，就是球拍刚体的原点。所有拍头量都在 `racket_head` 上计算，不是在拍柄根部。

## 3. 控制输入与施加力矩

控制是开环的：力矩 = f(关节, 时间)。每个关节的指令力矩是若干平滑脉冲之和（`src/control.ts`）：

```
tau_cmd_j(t) = Σ_p direction_p · peak_p · e_p(t)
e_p(t) = sin²(π (t − start) / duration)       0 < t − start < duration（默认 sin2 形状）
       = smoothstep 上升 / 平台 / smoothstep 下降   （plateau 形状，rise 默认 duration / 4）
       = 0                                    其他时间
```

两种脉冲形状都是 C¹ 连续的。MuJoCo `motor` 执行器（关节传动，gainprm = 1，无偏置、无激活动力学）的映射：

```
ctrl            = tau_cmd / gear                 h3d 写入 mjData.ctrl 的值
actuator_force  = clamp(ctrl, -1, 1)             ctrllimited，由 MuJoCo 自己裁剪
qfrc_actuator   = gear · actuator_force          作用在关节 dof 上的广义力矩
```

所以 gear 就是每个关节的力矩上限。`tau_cmd` 超过 gear 时，施加的力矩被截在 ±gear，`summary.joints[].saturated` 会标成 true。A/B/C 配置里没有任何关节饱和（有测试断言），施加力矩和指令力矩逐位相同。

运动完全由这些力矩产生：没有关键帧，没有位置伺服，没有直接写 qpos/qvel 的操作。只有初始姿态（静止）由配置给出，此后状态全部由正向动力学积分得到。

## 4. 积分与记录

- 积分器：RK4，dt = 0.5 ms，禁用接触，开启能量计算（`<flag energy="enable"/>`）。
- 每一步 k：
  1. 按 t_k 计算 `ctrl`，在本步内保持不变（零阶保持，ZOH）；
  2. `mj_forward` 得到 t_k 时刻自洽的 qacc、各类广义力、雅可比和能量，然后记录；
  3. `mj_step` 积分到 t_{k+1}。
- 第 k 个样本就是 t = k·dt 时刻的状态，样本数 = duration / dt + 1。

## 5. 输出量定义

| 列 / 字段 | 定义 |
| --- | --- |
| `q_*`、`dq_*`、`ddq_*` | 关节角 (rad)、角速度 (rad/s)、角加速度 (rad/s²)，即 qpos、qvel、qacc |
| `tau_cmd_*` | 指令力矩 (N·m) |
| `ctrl_*`、`actuator_force_*` | 写入的 ctrl 和 MuJoCo 裁剪后的执行器输出 |
| `tau_act_*` | 实际施加的执行器广义力矩 `qfrc_actuator` (N·m) |
| `tau_spring_*`、`tau_damper_*`、`tau_limit_*` | `qfrc_spring`、`qfrc_damper`、关节限位约束力 `qfrc_constraint` |
| `power_*` | 关节功率 P = qfrc_actuator · qvel (W)：实际广义力矩乘关节角速度，不是指令值 |
| `work_*` | 累计执行器功 (J)：W_{k+1} = W_k + tau_k · (q_{k+1} − q_k)。力矩在一步内恒定，所以这在离散意义上是精确的 |
| `vhead_from_*` | 该关节对拍头速率的贡献 qvel_i · (J_i · v̂)，所有关节加起来等于 \|v_head\| |
| `<site>_x/y/z` | 测点的世界坐标 (m) |
| `head_vx/vy/vz` | 拍头线速度 v = J_p · qvel，J_p 来自 `mj_jacSite` |
| `head_ax/ay/az` | 拍头线加速度 a = J_p · qacc + J̇_p · qvel，J̇_p 来自 `mj_jacDot` |
| `head_speed`、`head_acc`、`butt_speed` | 上面各量的模；`butt_speed` 是拍柄端速度，用于对比 |
| `kinetic_energy`、`potential_energy` | MuJoCo `energy[1]`、`energy[0]`（重力势能加弹簧势能） |
| `ang_momentum_z` | 整条链绕骨盆竖直轴的角动量 (kg·m²/s) = (M · qvel) 在根铰链 dof 上的分量 |

## 6. 自检（每次运行都计算，结果写进 summary 的 `validation` 字段）

| 检查 | 方法 | 上限 | A/B/C 实测 |
| --- | --- | --- | --- |
| 速度 | 位置的中心差分 vs J_p·qvel，最大误差除以峰值速度 | 0.01 | 1.5–1.8e-3 |
| 加速度 | 速度的中心差分 vs J_p·qacc + J̇_p·qvel，RMS 相对误差 | 0.1 | 2.1–3.1e-2 |
| 功能平衡 | \|W_act + W_damper + W_limit − ΔKE − ΔPE\| 在终点的值，除以执行器正功之和 | 0.01 | 1.2–3.0e-3 |
| 角动量 | ΔL_z vs 根铰链上所有广义力的冲量（执行器、弹簧、阻尼、限位） | 0.01 | 3e-5–1e-3 |

- 阻尼功和限位功用梯形积分，因为这两种力在一步内是变化的。弹簧能量已经包含在 ΔPE（energy[0]）里，不单独计入功，否则会重复计算。
- 加速度检查用 RMS 指标：关节限位是软约束，接触瞬间加速度很大，中心差分在那几个样本上误差偏大。
- 只有根铰链（`pelvis_rot`）上的力矩会和地面交换绕竖直轴的角动量，其余关节力矩都是链内的内力。

## 7. 近似与限制

- 平面链：5 个轴都是竖直的，没有肩上举、肩内外旋、前臂旋前旋后、腕桡尺偏，也没有躯干前屈和侧屈。真实挥拍中肩内旋和前臂旋前的贡献很大，这里完全没有。
- 原 A/B/C 模型的双腿固定，没有地面反力、蹬地、重心转移和下肢做功，骨盆力矩相当于由地面直接提供。独立肌肉实验中的 `muscle_lower_body.xml` 添加了足底接触，不改变 A/B/C 模型。
- 原有 A/B/C 模型使用理想力矩电机，没有肌肉的力-长度、力-速度关系或激活动力学；gear（力矩上限）、关节阻尼和脊柱扭转刚度 150 N·m/rad 都是假设值，没有对任何个体做标定。新增肌肉原型的限制见第 8 节。
- 关节限位是 MuJoCo 软约束。A/B/C 里肘关节（下限 0°，即完全伸直）、腕关节，以及 B 的肩关节都会碰到限位。B 在峰值前限位做功 −19.5 J，这部分能量被吸收掉了，结果对这个很敏感。
- 刚体体段：躯干是单一刚体，脊柱扭转集中在一个关节上。体段参数是缩放后的人群平均值。
- 没有球、没有拍弦接触，也没有空气阻力。"拍头速度"指弦床中心的运动学速度。
- A 的骨盆和躯干没有驱动但可以自由转动（只有脊柱弹簧和阻尼），会被手臂的反作用力带着反向旋转，A 的骨盆还会碰到 -70° 限位。A 不是"躯干锁死"的对照组。
- 结论只对 `experiments/abc.json` 这一组手工调出的脉冲成立，还没有做参数扫描和灵敏度分析。

## 8. 肌肉骨骼动力学主线

肌肉实验与五自由度球拍模型分开运行，配置在 `experiments/muscle-demo.json`，MJCF 为 `models/muscle_elbow.xml`、`models/muscle_shoulder_elbow.xml` 和 `models/muscle_lower_body.xml`。配置包含 `single-elbow`、`shoulder-elbow`、`squat-to-stand`、`countermovement-drive` 四组实验。

### 模块边界

- **Musculoskeletal Model**（`src/muscle-model.ts`）：MuJoCo `spatial tendon` 定义肌腱路径。每个肌肉配置最大等长力、最优纤维长度、肌腱松弛长度、最大收缩速度和激活动力学时间常数。由稀疏肌腱雅可比求力臂 `r = −dL/dq`，并用 `τ = rF` 汇总到关节。
- **Physics Simulation**（`src/muscle-simulate.ts`）：在当前姿态下计算肌腱长度、速度、力臂与肌肉力，经关节力矩接口送入 MuJoCo。支持未驱动浮动根自由度、正向积分和地面接触，并记录关节、身体测点、重心、接触力、压力中心、接触位置、肌腱路径与肌肉功率。
- **Motor Control**（`src/motor-control.ts`）：支持带平滑边沿的开环激活脉冲，也支持平滑关节轨迹、关节 PD 反馈、重心/骨盆平衡反馈和有界肌肉力分配。激励经不同的激活/去激活时间常数形成实际激活。
- 核心模块只依赖 MuJoCo、肌肉模型和控制模块，不导入 A/B/C、图表、动作导出或查看器代码。`src/muscle-cli.ts` 与 `src/motion-clip.ts` 是可选外围适配器，负责生成独立的 `h3d.motion.v1` 文件；静态查看器只读取该文件。

### 当前的力近似

- 纤维长度按 `max(0, tendon_length − tendon_slack_length)` 估算，肌腱不可伸长，忽略羽状角。
- 主动长度因子是以最优长度为峰值的高斯曲线。归一化速度 `v = tendon_velocity / (maxContractionVelocity · optimalFiberLength)` 为正时表示拉长：向心分支在 `v ≤ −1` 时为零、在 `−1 < v ≤ 0` 时使用 Hill 双曲线；离心分支在 `v > 0` 时以 `v = 0` 处相同的一阶导数平滑接续，并单调渐近于 1.8。各速度下的主动因子连续且位于 `[0, 1.8]`。
- 激活采用一阶变化率，激活和去激活可使用不同时间常数。
- 肌肉力参数和肌腱路径几何是演示用假设值，不是临床或个体标定数据；肌肉模型没有疲劳、弹性肌腱、肩胛运动或完整人体骨架。肘/肩实验的预设激活可能把关节推近软限位；下肢原型的模型边界见第 9 节。
- 双关节实验包含肱二头肌长头和肱三头肌长头两条跨肩/肘路径，另有肱肌和后束三角肌两条单关节路径。单关节实验仅模拟肘屈肌、肘伸肌。

### 力矩传递和轨迹自检

每个关节记录肌肉请求力矩、实际 `qfrc_actuator`、饱和比例 `|τ_requested| / |gear|`、跟踪误差和累计执行器功。累计功使用步前缓存的实际力矩：`W_{k+1} = W_k + τ_k (q_{k+1} − q_k)`。超出 `ctrlrange` 的力矩会体现在请求/实际差值和 `saturated` 标记中，不会被当成已经施加的肌肉力矩。

每块肌肉记录 `−F · tendon_velocity` 功率，并以梯形积分累计机械功；物理自检将肌肉总功率积分与实际关节功率积分比较。力臂误差在动作全程每 10 个积分步（通常 5 ms）做一次有限差分探测。运行汇总还提供最大力臂误差、请求/实际力矩误差、功一致性相对误差，以及所有记录量的有限值和宽松物理范围检查。单肘基准测试另在多个肘角验证力臂，并将 MuJoCo 角加速度与独立的刚体转动惯量计算比较。

生成供查看器读取的动作文件并启动静态服务：

```sh
npm run muscles
npm run web
```

仿真积分步长为 0.5 ms；动作导出每 10 个积分步采样一次，通常间隔 5 ms。若实验时长不落在固定步长网格上，最后一个积分步缩短，使 `samples.at(-1).time === duration`。静态服务只提供 `web/` 内容，不调用模拟器。

## 9. 下肢、骨盆、躯干与地面接触

### 模型与自由度

`models/muscle_lower_body.xml` 使用世界坐标 x 向前、y 向侧方、z 向上，长度单位为米。模型共 7 个广义自由度：

| 关节 | 类型 | 作用 | 肌肉直接驱动 |
| --- | --- | --- | --- |
| `root_x` | 滑动 | 根部前后平移 | 否 |
| `root_z` | 滑动 | 根部竖直平移 | 否 |
| `pelvis_tilt` | 铰链 | 骨盆前后倾斜 | 否 |
| `trunk_ext` | 铰链 | 躯干伸展/前屈 | 是 |
| `hip_ext` | 铰链 | 髋伸展/屈曲 | 是 |
| `knee_ext` | 铰链 | 膝伸展/屈曲 | 是 |
| `ankle_pf` | 铰链 | 踝跖屈/背屈 | 是 |

`trunk_ext`、`hip_ext`、`knee_ext`、`ankle_pf` 的肌肉合力矩由四个 MuJoCo torque actuator 施加；浮动根部与骨盆倾斜不直接伺服。闭环前馈使用 `stanceBiasTorques`：令 `c = qfrc_bias − qfrc_passive`，由 `mj_jacBody` 取支撑足的矢状面速度雅可比 `J`，解 `J_uᵀ λ = c_u`，再计算 `c − Jᵀ λ` 作为驱动关节的支撑偏置。模型节段质量或重力常数不在控制代码中硬编码；支撑雅可比按平面刚性足部假设消去接触反力。节段质量合计 70.3 kg：骨盆 11.17 kg、躯干和头臂合并段 34.2 kg、大腿 15.9 kg、小腿 6.98 kg、足 2.05 kg。

肌腱包含竖脊肌、腹直肌、臀大肌、髂腰肌、腘绳肌、股直肌、股肌群、腓肠肌、比目鱼肌和胫骨前肌。髋后侧与髌骨前侧路径采用 MuJoCo wrap cylinder。双侧臀、膝、踝和足部展示点位于 y 的两侧，但左右腿共用一套矢状面节段运动；模型不表示左右腿独立控制或侧向平衡。

### 接触、反力和观测量

地面是启用碰撞的平面，左右脚跟和前足各有一个球形接触几何体。MuJoCo 接触求解器给出活动约束的局部力，模拟器按接触坐标系转换到世界坐标，再计算总 GRF、左右足分力和垂直力加权的压力中心。`contactCount` 表示当前有活动接触约束的地面接触点数量；摆动阶段可以为 0。

记录还包含每块肌肉在当前时间点的 tendon wrap 三维折线路径，以及区域机械功率 `P = −F · tendon_velocity`。区域按下肢、躯干、上肢汇总；正值表示肌腱缩短方向的输出功率，负值表示吸收功率。该近似不会把跨关节肌肉功率解释成节段间能量流。

### 闭环控制

`TrajectoryController` 对关键姿态用 smoothstep 插值并计算参考角速度；关节反馈与重心、骨盆倾角反馈组成目标广义力矩，并叠加从当前 MuJoCo 状态计算的支撑偏置。控制器根据当前肌肉力臂和单位激活主动肌力，通过有界坐标迭代分配 0–1 的激活值，再经一阶激活动力学送给肌肉模型。姿态/重心目标和反馈增益仍是两个演示动作的手工参数，不是轨迹优化、MPC 或生理控制模型。

`squat-to-stand` 从约 0.72 m 的骨盆高度开始，目标是伸展站起；`countermovement-drive` 从站姿下沉后蹬伸回支撑。两者的足底反力均来自 MuJoCo 接触约束，而非动画或预设曲线。测试还覆盖支撑投影的静力平衡、模型总质量缩放 1.25 倍、初始关节角扰动、执行器饱和记录、全轨迹有限差分力臂和做功一致性。

### 近似与限制

- 节段与接触构成二维共享腿模型；没有独立左右髋膝踝、侧向躯干控制、脚掌滚动关节、足趾或真实人体蒙皮。
- 肌腱不可伸长，肌肉力模型未标定；支撑偏置由当前模型反演，但姿态增益和重心目标仍是演示参数，且假定平面内足部刚性支撑。MuJoCo 足底接触是柔性约束，实际接触运动与理想支撑投影不会完全相同。
- 接触力是刚体接触求解结果，取决于接触几何、摩擦和 solver 参数；不能视作实测测力台数据。
- 闭环反馈展示给定轨迹在模型中的执行，不保证对其他体型、初始姿态或动作目标有效。

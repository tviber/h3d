# 五个基础动作设计

## 姿势来源与选择

参考 Shisei 的标准姿势目录及正视图，原始参考条目另存 `selected-pose-references.json`。该库是静态图像参考，没有可用的连续运动、接触力或骨骼动画；本轮没有把图像宣称为可恢复的精确三维测量。五种选择是面向日常活动范围的工程判断，不是人体使用频率统计。

| 动作 | 参考 | 时长 | 动态设计 |
| --- | --- | --- | --- |
| 站姿左右移重 | [P015](https://shisei.indaloop.app/en/pose/P015/) | 6 s | 骨盆左右小幅侧移，双脚保持支撑，换侧前回正 |
| 双臂上举放下 | [P019](https://shisei.indaloop.app/en/pose/P019/) | 5 s | 从下垂进入约 165° 屈肩，肘轻屈，停留后放下 |
| 下蹲起立 | [P058](https://shisei.indaloop.app/en/pose/P058/) | 5 s | 按自身腿长下降约 32%，躯干轻前倾，手臂前伸平衡，再回站姿 |
| 髋折叠与直立 | [P064](https://shisei.indaloop.app/en/pose/P064/) | 5 s | 髋后移、膝微屈，躯干前倾约 45°，停留后回正 |
| 左右转体 | [P073](https://shisei.indaloop.app/en/pose/P073/) | 7 s | 脚底不转，躯干左右各约 35°，双臂展开，经过中立位换侧 |

这些是从姿势的主要意图设计的简化运动，未完全复刻图中的叉腰、手落膝、双手接触或脚尖细节。界面称“重心转移”指骨盆移位的运动学设计；没有计算实际质量分布和动态平衡。

## 如何从静态目标变成动作

人工设定中立位、目标位和支撑状态，按每个角色的腿长/臂长构造目标，不逐顶点插值。时间曲线使用五次缓动 `6t^5-15t^4+10t^3`，使进出保持阶段的速度和加速度归零；转体采用四元数增量，肢体保持骨长，腿部使用双骨 IK 和双脚可达性投影。双侧动作拆分为左侧进入/保持/回正、右侧进入/保持/回正。跳帧由时间直接求解。

这批是 `authored-humanoid` 人工运动学片段，与原来的 MuJoCo 物理动作共存。界面隐藏该批次的肌力、GRF、功率和 COM 数值，显示“动作设计预览 · 非物理仿真”。尚不包含肩胛节律、手指、衣物碰撞、体积避碰或动力学平衡控制。

本轮在 MakeHuman 通用路径与 CesiumMan 检查五种动作正侧视。标准模型的主动作可辨认，部分极限肩位仍需肩胛/扭转骨改进；不能称为生产级全身动作或运动训练标准。浏览器检查未见脚本异常。

`npm run poses` 导出 `out/basic-motions.json`，可通过页面“导入动作 JSON”单独加载这五个片段。源定义在 `web/avatar/basic-motions.js`，不修改物理求解器。自动化覆盖曲线连续性、端点返回、骨长保持和跳帧确定性；共 84 项测试通过。
